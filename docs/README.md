## 仍需确认或联调

1. 吉客云真实返回数组及结束条件、品牌精确过滤、最大页大小、限流额度、停用商品默认是否包含。官方已明确 lastMaxId 续拉；首期不存外部商品身份，因此采用全量内容比对，不承诺可靠 SKU 增量或完整历史批次回放。
2. 数量为 0 的业务含义、固定补贴上限范围、比例精度/范围、金额舍入与计算基数来源。
3. 时间端点、覆盖优先级、不同政策不限颜色与指定颜色交集的替换、旧政策恢复、局部生效及后续新增颜色对既有政策的适用规则。颜色范围本身已明确，不再把空颜色是否通配列为未定：必须用 color_scope 表达。
4. 管理员名单、跨人可见范围、自审及拒绝原因要求；默认不扩大租户范围。
5. 附件、备注及链接必填要求和权限、容量；实际部署域名及多实例会话。
6. 普通浏览器飞书网页授权的真实联调：重启服务后确认实际访问地址、飞书重定向 URL、后端来源白名单一致，验证授权返回、刷新恢复、取消与超时重试。登录代码和自动化测试已完成，尚未确认真实浏览器授权成功；步骤见 [飞书鉴权](architecture/feishu-auth-flow.md)。
