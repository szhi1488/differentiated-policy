# 管理员工作台

更新日期：2026-11-13。

管理员登录后进入 `#/admin/catalog/sources`。点击左侧「商品」可展开或收起「源商品库」「商品清洗与识别」和「商品中心」。进入任一子页面时，分组自动展开并高亮当前页面。旧管理员地址由路由守卫统一跳回源商品库。申请人访问管理员地址时回到 `#/apply`。客户端免登、浏览器扫码及网页授权都按服务端会话的 `user.roleType` 分流。[飞书鉴权](feishu-auth-flow.md)

## 源商品库

右上角「导入商品」打开弹窗。选择 OPPO 或一加、全量导入或按建档日期导入。按建档日期时必须选择日期。在品牌页签中打开弹窗会带入当前品牌；有活动任务时优先显示其状态、读取数和去重数。暂停后可继续或结束。同账套每次处理一个导入任务，导入完成后等待管理员发起清洗。

筛选栏左侧为建档日和关键词，右侧为重置和查询。可结合品牌页签查看指定建档日的商品，分页保留已应用的筛选条件。弹窗中的建档日任务已有入库结果时，「查看该日商品」会直接应用对应品牌与日期。建档日取自按日导入命中，缺少确认记录时显示「—」。

表格分别显示 `gmtModified` 对应的 SKU 修改时间和 `goodsGmtModified` 对应的商品修改时间，均为北京时间，非零毫秒保留三位。分页栏的「前往」可输入页码后按回车跳页。窄屏可打开侧栏，表格在自身容器内横向滚动。

布局由 `frontend/src/layouts/AdminLayout.vue` 提供，页面为 `frontend/src/views/admin/catalog/CatalogSourcesPage.vue`。任务轮询和列表状态由 `useSourceGoods` 管理。后端接口和配置见[商品管理接口](../api/catalog-api.md)与[项目 README](../../README.md#吉客云商品导入)。

## 商品清洗与识别

清洗页 `#/admin/catalog/cleaning` 默认汇总 OPPO 和一加的当前来源商品。品牌、建档日期和商品名称或货号用于筛选。建档日期可选不限、指定一天或建档日未知。页签显示同一筛选范围内的全部、待清洗、待人工审核、已通过、技术失败和已排除。已通过包含自动和人工通过。

右上角「开始清洗」打开商品预览。选择品牌和指定建档日期，或选「该品牌全部已入库商品」纳入建档日未知的 SKU。预览按 SKU 分页，显示商品名称、货号、SKU 名称、建档日期、已识别机型和状态。关键词只筛选预览表。预计数量默认统计导入已完成或已结束的待清洗 SKU，可同时重新识别未建立映射的待审商品。二次确认框居中展示范围和数量，「返回预览」保留已选范围。当前页面任务受理后显示进度和日志入口。适配新基线后，「清洗记录」保留进度和结果统计，移除清洗日志入口。

来源详情显示原文、识别证据和处理记录。「来源原文」在「分类名称」下显示完整分类路径 `cateFullName`，缺值显示「—」。待审商品保留系列、型号、配置和颜色四个填写框，底部直接点「审核通过」或「审核不通过」，无需填写原因。通过须填齐四项，命中排除规则时禁用「审核通过」。不通过后进入「已排除」，服务端自动保存审核结果。窄屏时弹窗内容可滚动，底部按钮保持可见。状态冲突保留填写内容，重新读取候选后可提交。技术失败可从列表逐条重试。[商品管理接口](../api/catalog-api.md) · [清洗细则](../business/catalog-cleaning.md)

## 商品中心（静态预览）

已确认的空库基线按品牌、系列、机型版本、配置和颜色保存标准商品。清洗写入及商品中心真实接口接入待实现。[商品目录设计](catalog-admin-design.md)

从「商品 → 商品中心」进入 `#/admin/catalog/center`。页面使用 OPPO 和一加的 24 条本地示例商品，提供统计、品牌系列树、关键词和状态筛选、分页、详情和数据字典。列表的「商品信息」显示货号和 SKU，手机缩略图与来源名称可在详情查看。图标和手机缩略图使用 SVG。导出和导入模板使用示例 CSV，批量导入仅展示入口。页面不请求商品接口，源商品库和清洗页的接口保持原样。

「数据字典」维护品牌、系列和颜色。系列归属品牌。颜色表中的每个颜色可供所有商品选择。被商品引用的字典项和含系列的品牌不能删除。

点击商品行的「编辑」打开右侧抽屉。品牌和系列从字典联动选择，切换品牌会清空旧系列。机型和配置在商品中填写，颜色从独立颜色表选择。货号与 SKU 用于识别当前商品。商品和字典改动仅保留在本页预览，刷新或离开后恢复示例。取消有未保存的商品修改时需确认是否放弃。

点击「新增商品」打开同样的右侧抽屉。新增表单默认选择「待上架」，保存时生成示例货号和 SKU，更新预览列表及统计。新增商品符合当前筛选时，列表定位到该商品所在页。

在桌面端，拖动各数据列标题右侧的分隔条可调宽或调窄列。勾选列和右侧操作列宽度固定；窄屏仍可在表格内横向滚动。
