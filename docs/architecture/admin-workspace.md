# 管理员展示工作台

更新日期：2026-11-11。本轮按用户要求实现管理员登录后的展示页面；业务按钮不接后端、不写数据库、不修改审核状态。

## 登录与路由

`App.vue` 使用服务端返回的 `user.roleType` 分流：ADMIN 默认进入 `#/admin/policies`，其他角色进入 `#/apply` 并沿用申请人工作台。Vue Router 使用 Hash 路由，支持浏览器前进、后退及直接访问，不新增服务器路径重写要求；OAuth 回调仍固定为 Origin 的 `/`，授权参数仍先清除再交换。

管理员合法子路由会保留；未知地址回到全部政策。申请人手动访问管理员路由会返回申请人页。前端分流只控制展示，不能代替未来业务接口对有效账号、ADMIN 和租户的实时校验。角色来自登录会话快照，修改数据库角色后应重新登录，不提供前端角色开关。

| Hash 路由 | 展示内容 |
| --- | --- |
| `#/admin/overview` | 待审政策、商品异常、可用规格、技术失败卡片，待处理队列与处理流程 |
| `#/admin/policies` | 状态页签、渠道/平台/核销/场景/申请人/提交日期/关键词筛选、分页、政策详情 |
| `#/admin/reviews` | 待审队列、当前轮次、逐平台补贴、历史、候选影响和禁用的审核操作区 |
| `#/admin/catalog/sync` | 导入与清洗独立阶段、演示分流数量、任务列表及详情 |
| `#/admin/catalog/sources` | 来源商品、清洗状态、七字段只读原文、候选证据、当前映射 |
| `#/admin/catalog/exceptions` | 缺失/歧义/冲突队列，核对预览及禁用的确认/排除按钮 |
| `#/admin/catalog/variants` | 品牌/系列/型号/配置、独立颜色集合、目录状态 |
| `#/admin/catalog/logs` | SYSTEM/USER 操作、依据和变更前后结果 |
| `#/admin/settings` | 当前账号、接入边界与待确认事项，无权限修改功能 |

## 展示边界

业务样例集中在 `frontend/src/views/admin/data/demo.js`，以 DEMO 编码及演示姓名标记，页面持续提示展示模式。身份区使用实际登录身份；业务表格使用本地样例。不会将样例写入标准库、政策表或浏览器存储。统计仅为这些样例的展示计数，不增加经营分析功能。

可用交互仅包括导航、筛选、重置、分页、详情开合与页签切换。审核、任务创建/暂停/恢复、技术重试、映射确认/排除、规格及颜色维护按钮均禁用；不显示成功通知，不调用相关业务接口。附件不提供假下载链接。状态页签保留草稿空状态。

详情展示不同平台独立的数量及补贴，金额与比例使用十进制文本，不进行金额计算。未填数量不补为 0；百亿核销/场景/预估显示不适用。不限颜色与具体颜色明确区分。已通过不等于当前生效，候选影响显示口径待确认，不能解释为无覆盖。历史仅为样例结构，真实各轮不可变快照查询仍待接入。

清洗状态与当前映射分别展示，技术失败样例保留旧映射；颜色缺失不变成不限颜色。系统操作不冒用管理员，人工结果保护、停用不复活、历史快照不改写均提示边界，不能据此声称实际解析器或审计已实现。商品仍只涉及两品牌七原始字段。

## 组件与验证

页面使用 Element Plus 按需组件和中文语言包；工作台与子页延迟加载。`constants/admin.js` 管理导航与状态，`composables/useAdminPolicies.js` 管理筛选与分页，`router/index.js` 管理路由。管理员样式限定在 `views/admin/admin.css` 业务类中。

本轮前端检查结果见整体架构的最新记录。浏览器检查覆盖 1440、768、390px，已观察侧栏折叠、筛选换行、表格容器内横向查看、固定操作列、详情、历史和异常证据展示。真实账号由用户完成授权后，已观察到 `http://127.0.0.1:5173/#/admin/policies` 与采购管理员身份；其他界面检查使用隔离的本机组件预览，不能当作真实商品或政策接口联调。取消授权、超时、退出重登与部署环境仍须单独验证。本轮不连接数据库、不建表、不改后端或飞书远端配置。
