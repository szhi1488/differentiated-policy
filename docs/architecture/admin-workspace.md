# 管理员工作台

更新日期：2026-11-13。

管理员登录后进入 `#/admin/catalog/sources`。点击左侧「商品」可展开或收起「源商品库」「商品清洗与识别」和「商品中心」。进入任一子页面时，分组自动展开并高亮当前页面。旧管理员地址由路由守卫统一跳回源商品库。申请人访问管理员地址时回到 `#/apply`。客户端免登、浏览器扫码及网页授权都按服务端会话的 `user.roleType` 分流。[飞书鉴权](feishu-auth-flow.md)

## 源商品库

右上角「导入商品」打开弹窗。选择 OPPO 或一加、全量导入或按建档日期导入。按建档日期时必须选择日期。在品牌页签中打开弹窗会带入当前品牌；有活动任务时优先显示其状态、读取数和去重数。暂停后可继续或结束。同账套每次处理一个导入任务，导入完成后等待管理员发起清洗。

筛选栏左侧为建档日和关键词，右侧为重置和查询。可结合品牌页签查看指定建档日的商品，分页保留已应用的筛选条件。弹窗中的建档日任务已有入库结果时，「查看该日商品」会直接应用对应品牌与日期。建档日取自按日导入命中，缺少确认记录时显示「—」。

表格分别显示 `gmtModified` 对应的 SKU 修改时间和 `goodsGmtModified` 对应的商品修改时间，均为北京时间，非零毫秒保留三位。分页栏的「前往」可输入页码后按回车跳页。窄屏可打开侧栏，表格在自身容器内横向滚动。

布局由 `frontend/src/layouts/AdminLayout.vue` 提供，页面为 `frontend/src/views/admin/catalog/CatalogSourcesPage.vue`。任务轮询和列表状态由 `useSourceGoods` 管理。后端接口和配置见[商品管理接口](../api/catalog-api.md)与[项目 README](../../README.md#吉客云商品导入)。

## 商品清洗与识别

清洗页 `#/admin/catalog/cleaning` 默认汇总 OPPO 和一加的当前来源商品。品牌、建档日期和商品名称或货号用于筛选。建档日期可选不限、指定一天或建档日未知。页签显示同一筛选范围内的全部、待清洗、待人工审核、已通过、技术失败和已排除。已通过包含自动和人工通过。

右上角「开始清洗」打开商品预览。选择品牌和指定建档日期，或选「该品牌全部已入库商品」纳入建档日未知的 SKU。预览按 SKU 分页，显示商品名称、货号、SKU 名称、建档日期、已识别机型和状态。关键词只筛选预览表。预计数量默认统计导入已完成或已结束的待清洗 SKU，可同时重新识别未建立映射的待审商品。二次确认框居中展示范围和数量，「返回预览」保留已选范围。任务受理后显示进度。「清洗记录」显示每轮通过、待审、失败和跳过的数量。

来源详情显示原文、识别证据、当前商品映射和最近人工审核结果。「来源原文」在「分类名称」下显示完整分类路径 `cateFullName`，缺值显示「—」。待审商品保留系列、型号、配置和颜色四个填写框，底部直接点「审核通过」或「审核不通过」，无需填写原因。通过须填齐四项，命中排除规则时禁用「审核通过」。不通过后进入「已排除」，服务端自动保存审核结果。窄屏时弹窗内容可滚动，底部按钮保持可见。状态冲突保留填写内容，重新读取候选后可提交。技术失败可从列表逐条重试。[商品管理接口](../api/catalog-api.md) · [清洗细则](../business/catalog-cleaning.md)

## 商品中心

从「商品 → 商品中心」进入 `#/admin/catalog/center`。统计、品牌／系列／机型分类、筛选、分页和详情读取公司标准目录。点系列展开机型并查看该系列，点机型筛选对应机型版本。分类搜索支持机型名称，「仅看在售商品」同步更新各级计数。品牌、商品状态、系列和配置下拉选中即刷新列表并回到第一页。切换品牌会清除不匹配的系列及机型。关键词可按回车或点「查询」，点清除立即刷新。「商品信息」上方显示源商品的吉客云 SKU ID，下方显示标准商品货号，字段为空时显示「—」，有货号时可点击复制图标。多条来源归并时，列表和详情取本地来源 ID 最小的一条。销售状态为空时显示「未知」。详情的来源名称取同一条来源的吉客云 `goodsName`。商品名称、配置、筛选项及抽屉把 1024GB 存储显示为 1T。列表支持按更新时间排序，「更多操作」可导出当前页。[商品管理接口](../api/catalog-api.md)

可下载导入模板。标准商品批量导入入口待接入。新增商品通过右侧抽屉保存，分别填写 RAM、ROM，ROM 可填 1T。普通机型可留空版本，销售状态默认「待上架」。保存后刷新列表和统计，手工新增的商品尚无来源 SKU 或货号。编辑抽屉可查看字段，保存修改待接入。每行「删除」须确认，提交后停用该商品，从默认列表和统计移除，并保留来源和政策引用。数据字典读取真实品牌、系列和颜色，支持新增及未引用条目的改名和删除。已有引用的条目保留原名称与关系。商品抽屉读取同一套字典选项。
