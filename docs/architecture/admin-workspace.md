# 管理员工作台

更新日期：2026-11-12。

管理员登录后进入 `#/admin/catalog/sources`。左侧「商品」分组包含「源商品库」和「商品清洗与识别」。旧管理员地址由路由守卫统一跳回源商品库。申请人访问管理员地址时回到 `#/apply`。客户端免登、浏览器扫码及网页授权都按服务端会话的 `user.roleType` 分流。[飞书鉴权](feishu-auth-flow.md)

## 源商品库

右上角「导入商品」打开弹窗。选择 OPPO 或一加、全量导入或按建档日期导入。按建档日期时必须选择日期。在品牌页签中打开弹窗会带入当前品牌；有活动任务时优先显示其状态、读取数和去重数。暂停后可继续或结束。同账套每次处理一个任务，后端在导入成功后排入清洗。

筛选栏左侧为建档日和关键词，右侧为重置和查询。可结合品牌页签查看指定建档日的商品，分页保留已应用的筛选条件。弹窗中的建档日任务已有入库结果时，「查看该日商品」会直接应用对应品牌与日期。建档日取自按日导入命中，缺少确认记录时显示「—」。

表格分别显示 `gmtModified` 对应的 SKU 修改时间和 `goodsGmtModified` 对应的商品修改时间，均为北京时间，非零毫秒保留三位。分页栏的「前往」可输入页码后按回车跳页。窄屏可打开侧栏，表格在自身容器内横向滚动。

布局由 `frontend/src/layouts/AdminLayout.vue` 提供，页面为 `frontend/src/views/admin/catalog/CatalogSourcesPage.vue`。任务轮询和列表状态由 `useSourceGoods` 管理。后端接口和配置见[商品管理接口](../api/catalog-api.md)与[项目 README](../../README.md#吉客云商品导入)。

## 商品清洗与识别

`#/admin/catalog/cleaning` 默认可查看最近成功导入的批次。在「清洗任务 → 源商品品牌」选择 OPPO 或一加后，任务卡、分类数量和结果表切到该品牌最近成功的批次。手动启动和整批重试要求选定品牌，重置结果筛选时保留品牌选择。运行时轮询进度。结果支持服务端分类、关键词、规则版本筛选及分页。商品详情展示原文和识别证据，可提交审核或排除。版本冲突时保留编辑，待管理员重新读取候选后再提交。技术失败可逐条或按批次重试，日志按批次分页查询。当前规则为 `v1.2.0`，旧规则下未映射的待审项可通过「重新识别待审」重新处理。[商品管理接口](../api/catalog-api.md) · [自动清洗细则](../business/catalog-cleaning.md)
