# 管理员工作台

更新日期：2026-11-12。

管理员登录后进入 `#/admin/catalog/sources`。左侧导航只有「商品」分组及其下的「源商品库」。旧管理员地址由路由守卫统一跳回源商品库。申请人访问管理员地址时回到 `#/apply`。客户端免登、浏览器扫码及网页授权都按服务端会话的 `user.roleType` 分流。[飞书鉴权](feishu-auth-flow.md)

源商品库提供「导入OPPO手机」「导入一加手机」两个入口。同账套每次处理一个任务，分别显示读取条数、去重条数和状态。暂停时可以冷却后继续，或确认结束；已入库数据保留。品牌页签、关键词和分页查询数据库中的七字段原文。分页栏的「前往」可输入页码并按回车跳页，跳页沿用当前筛选条件和每页条数。导入成功后显示等待清洗，清洗功能待接入。窄屏可打开侧栏，表格在自身容器内横向滚动。

布局由 `frontend/src/layouts/AdminLayout.vue` 提供，页面为 `frontend/src/views/admin/catalog/CatalogSourcesPage.vue`。任务轮询和列表状态由 `useSourceGoods` 管理。后端接口和配置见[商品管理接口](../api/catalog-api.md)与[项目 README](../../README.md#吉客云商品导入)。

2026-11-11 使用模拟会话及商品 API 检查生产构建：管理员 1440×1000 默认入口、768×1000 旧链接回退、390×844 直接访问均通过。两个导入入口分别提交、活动任务互斥、冷却提示、结束确认取消、继续导入、品牌和关键词筛选、翻页及接口错误态均通过。三种尺寸无页面级横向溢出，平板和手机表格在容器内滚动。`npm.cmd run check` 通过 17 个文件的 65 项测试及生产构建。
