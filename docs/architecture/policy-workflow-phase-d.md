# D 阶段工作台交付（P18–P22）

D 阶段最初提供独立经办列表与站内两级审核。「待我审核」页面现已移除。运营在本轮飞书私聊卡上办理初审，采购在管理员「差异化政策」终审，批准即结束。办理权来自当前轮的有效指派。目标环境使用 B 阶段数据库基线和按轮指派。[切换条件](policy-workflow-phase-b.md#切换与运行边界)

2026-11-24，申请人沿用本阶段的选单页面，产品运营从飞书交互卡办理。新轮审核详情可逐段核对原执行名单、申请人已选及未选的候选政策。此前隔离环境验证了逐人私聊审核卡、卡上通过或拒绝。现行流程私聊下一环节办理人，采购终审通过后发群公告。真实企业收件、手机工作台办理和目标 MySQL 列入 P32。[E 阶段交付与验收](policy-workflow-phase-e.md)

## 工作台入口

| 编号 | 入口 | 可以办理或核对的内容 |
| --- | --- | --- |
| P18 | 产品运营的飞书私聊卡 | 卡上通过后转采购，退回时原因必填。卡上显示本轮叠加政策、机型配置和对应补贴。 |
| P19 | 管理员「政策管理 → 差异化政策」 | 可用「审核阶段」筛选初审和终审，查看实际初审人与时间。知悉中的采购可阅读本轮依据，取得终审权的成员才可批准或驳回。支持继续按原筛选条件查看政策和历轮快照。[采购接口](../api/admin-api.md) |
| P20 | 申请人「我的提交」和「继续编辑」 | 待审申请显示当前阶段。驳回后从本轮日志显示退回环节、实际退回人、北京时间和原因。原申请人修改后以原单号重提，服务端按当时名单冻结新一轮。平台移交仍由原申请人修改自己的申请。[申请人接口](../api/policy-api.md) |
| P21 | 管理员「系统管理 → 政策审核设置」及「差异化政策 → 当前申请详情 → 改派本轮成员」 | 默认名单按姓名、部门查找，跨页按本地用户 ID 勾选两组人员。在途改派独立核对目标环节、完整名单及原因。保留者沿用原指派和待办，未来采购的待办在转入终审时登记。[设置与改派说明](../api/policy-review-settings.md) |
| P22 | ERP 站内按轮路由 | 登录后按链接指定的单号和轮次重新核权。采购终审链接打开「差异化政策」的对应单据，办理前校验轮次和权限。运营详情和历史轮只读。退回修改链接只对原申请人本轮仍被驳回的申请打开表单。 |

## 办理链接约定

运营在飞书初审卡上提交决定。采购收到「待你采购终审 · 单号 · 第 N 轮」后，从飞书工作台打开「差异化政策管理系统」，进入「政策管理 → 差异化政策」，按单号查找对应行并点「审核」。原申请人从「我的提交」找到退回的原单继续编辑。群公告、私聊卡及个人待办按已确认规则取消业务跳转，ERP 在相应节点结束后结办已登记的任务。[通知规则和待对齐的改期消息](policy-workflow-phase-e.md#终审通过的群公告)

以下是 ERP 支持的站内 Hash 路径，供工作台路由和已有普通书签使用。

| 用途 | 站内路径示例 |
| --- | --- |
| 查看第 2 轮 | `/#/reviews/57?round=2` |
| 第 2 轮采购终审 | `/#/admin/policies?policyId=57&round=2` |
| 原申请人修改第 2 轮退回的原单 | `/#/apply?policyId=57&round=2` |

旧普通网址继续受对应轮次与身份限制。若打开工作台首页时一直转圈，先在该设备核对网页应用主页和网络。[网络排查与历史群链接](environment-configuration.md#从飞书群打开内网政策链接)

审核页将 `round` 传给按轮详情及下载接口的 `submissionVersion`。按轮详情始终只读。原申请人修改页保留 `#/apply?policyId=57&round=2`，通过本人申请接口重新读取版本和状态后才展示表单。切换目标前沿用未保存确认，取消后保留原地址、输入和附件。

客户端免登保留当前 Hash。普通浏览器的扫码和网页授权共用固定的站点根回调，标签页只保存这次 OAuth state 对应的站内办理路径。回调清除授权参数并一次性恢复目标；工作台等服务端确认身份后才挂载。回跳解析校验目标路由、单据和轮次，拒绝重复或额外参数。授权范围由服务端按本轮重新计算。[飞书登录流程](feishu-auth-flow.md)

## 管理员打开政策详情

「差异化政策 → 查看」先读取申请快照，展示机型、商品、补贴和附件，再独立读取本轮审核成员及决定。主详情请求失败时，弹窗显示「重新读取政策」。仅成员请求失败时，已读内容继续显示，在「本轮审核信息未能读取」处点「重新读取本轮审核信息」即可单独重试。若单据版本已经变化，按提示重新读取政策。[管理员工作台](admin-workspace.md#差异化政策)

普通「查看」用于查阅政策及审核结果，在途成员可由管理员按权限改派。办理采购终审从「差异化政策」的「审核」进入，后端重新核对单号、轮次、记录版本与办理资格。遇到整窗「服务暂时不可用」时，先区分主详情和按轮请求哪一个失败。本地回归已验证快照带额外展示字段时可以正常读取，以及成员请求返回 500 时原详情仍可见。截图本身无法确定是哪一个请求失败。[详情接口](../api/admin-api.md#列表与详情) · [现行详情验收](frontend-harness.md#2026-11-24-现行数据契约与政策详情验收)
